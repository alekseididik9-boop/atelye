# ♕ Korona Atelier — Веб-приложение индивидуального пошива одежды

Полнофункциональное веб-приложение для премиального ателье «Korona Atelier», разработанное в рамках дипломного проекта. Проект сочетает в себе элегантный пользовательский интерфейс в темных тонах с золотыми акцентами и надежную серверную бизнес-логику.

---

## 🛠 Технологии и стек

### Backend:
* **Python 3.10+** / **Django 4.x** / **Django REST Framework (DRF)**
* База данных: **SQLite** (для разработки)
* Аутентификация: Token / Session Authentication

### Frontend:
* **React** (собрано с помощью **Vite**)
* **Bootstrap 5** + кастомные премиальные стили CSS (темная тема, золотые акценты, шрифты с засечками)
* **React Router DOM** (клиентская маршрутизация)
* Axios (для взаимодействия с REST API)

---

## 🌟 Основной функционал

1. **Интерактивный каталог**:
   - Динамическая загрузка услуг и коллекций тканей с бэкенда.
   - Карточки товаров с уникальными изображениями и плавной анимацией при наведении.
2. **Личный кабинет клиента**:
   - Авторизация, регистрация и профиль пользователя.
   - Оформление заказа индивидуального пошива с выбором услуг и тканей.
3. **Панель мастера / Администратора**:
   - Управление заказами, изменение их статусов (принят, в работе, готов и т.д.).
4. **Дизайн и UX**:
   - Выдержанный премиальный стиль бренда (темная палитра, золотые элементы, шапка и фирменный футер с контактами).
