# 👔 CRM-система и API для ателье мужских костюмов

Бэкенд-часть веб-приложения для автоматизации работы премиального ателье. Проект предоставляет защищенный REST API для управления каталогом тканей, услугами, мерками клиентов и оформлением заказов. 
Разработано в строгом соответствии с паспортом MVP.

## 🛠 Технологии
* **Язык:** Python 3
* **Фреймворк:** Django + Django REST Framework (DRF)
* **База данных:** PostgreSQL
* **Авторизация:** JWT (JSON Web Tokens)
* **CORS:** Настроен для интеграции с React-фронтендом (порт 3000)

## 🗄 Архитектура базы данных (5 моделей)
1. **User** — встроенная модель Django. Роли разделены флагом `is_staff` (False — Клиент, True — Мастер/Администратор). Номер телефона сохраняется в поле `username`.
2. **Fabric** — справочник тканей.
3. **Service** — справочник предоставляемых услуг.
4. **Measurement** — индивидуальные мерки (привязаны к клиенту, каскадное удаление).
5. **Order** — центральная сущность бизнес-логики (связывает Клиента, Ткань, Услугу и Мерки). Защита от удаления связанных справочников (`PROTECT`).

## 🔐 Бизнес-логика и права доступа (Permissions)
В проекте реализовано строгое разделение прав:

* **Гости (без токена):** Могут только регистрироваться и просматривать каталог тканей и услуг (GET-запросы).
* **Клиенты (с токеном):** Могут создавать и просматривать **только свои** мерки и заказы. При создании заказа или сохранении мерок ID клиента привязывается сервером автоматически из JWT-токена. Новый заказ всегда получает статус `NEW`.
* **Мастер / Администратор (is_staff=True):** Имеет глобальный доступ. Может редактировать каталоги (добавлять/удалять ткани и услуги), видит заказы абсолютно всех клиентов и имеет право менять их статус (`IN_PROGRESS`, `DONE`).
