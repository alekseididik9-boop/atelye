# 👔 CRM-система и сайт для ателье мужских костюмов

Бэкенд-часть веб-приложения для автоматизации работы премиального ателье. Проект предоставляет REST API для управления каталогом тканей, услугами, мерками клиентов и оформлением заказов.

## 🛠 Технологии
* **Язык программирования:** Python 3
* **Фреймворк:** Django + Django REST Framework (DRF)
* **База данных:** PostgreSQL
* **Авторизация:** JWT (JSON Web Tokens)

## 🗄 Архитектура базы данных
В проекте реализовано 5 связанных моделей:
1. **User** — пользователи системы. Разделены на 2 роли (Клиент и Администратор/Портной).
2. **Fabric** — каталог тканей и материалов.
3. **Service** — каталог предоставляемых услуг (например, "Пошив костюма").
4. **Measurement** — индивидуальные мерки клиентов (связь с User).
5. **Order** — главный бизнес-процесс. Связывает клиента, выбранную ткань, услугу и мерки в единый заказ с отслеживанием статуса (NEW, IN_PROGRESS, DONE).

## 🚀 Основной функционал (API)
* Регистрация и JWT-авторизация пользователей.
* Открытый просмотр каталога тканей и услуг.
* Сохранение и управление личными мерками (только для авторизованных клиентов).
* Оформление заказов.
* Управление статусами заказов (только для администраторов).
