# Korona Atelier (Ателье «Корона») ♕

Веб-приложение для сервиса индивидуального пошива одежды. Проект состоит из REST API бэкенда на Django и интерактивного SPA-фронтенда на React.

## 🌟 Основной функционал
* **Для клиентов:** 
  * Просмотр каталога услуг и тканей.
  * Регистрация и авторизация (на базе JWT-токенов).
  * Оформление заказов на пошив и отслеживание статуса в личном кабинете.
* **Для мастеров (Админ-панель):** 
  * Удобная рабочая зона для просмотра всех заказов.
  * Доступ к контактным данным клиента (Имя, Телефон, Email).
  * Быстрое управление статусами заказов (Новый, В работе, Готов, Выдан).
* **Система уведомлений:** Автоматическая отправка Email-писем клиентам при оформлении заказа и при смене его статуса мастером.

## 🛠 Стек технологий
* **Frontend:** React, Vite, React Router DOM.
* **Backend:** Python, Django, Django REST Framework, PostgreSQL.

## 🚀 Запуск проекта для разработки

### Бэкенд
1. Перейдите в папку бэкенда и активируйте виртуальное окружение.
2. Установите зависимости (если есть `requirements.txt`): `pip install -r requirements.txt`
3. Примените миграции: `python manage.py migrate`
4. Запустите сервер: `python manage.py runserver`

### Фронтенд
1. Перейдите в папку `frontend`.
2. Установите модули: `npm install`
3. Запустите сборщик: `npm run dev`
